## Screenshot tips

- Zoom in (`Ctrl +`) so wire colours are clearly visible
- Make sure the circuit label and both input/output values are in frame
- **Windows:** `Win + Shift + S` (Snip & Sketch) or Snipping Tool
- **macOS:** `Cmd + Shift + 4` then drag to select area
- **Linux:** `gnome-screenshot -a` or press `Print Screen`
- Save as **.png** format (not .jpg or .bmp)
