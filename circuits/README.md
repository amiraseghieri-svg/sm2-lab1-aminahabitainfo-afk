# circuits/

Place your Logisim-Evolution circuit files (`.circ`) in this folder.

## Required files for Lab 01

| Filename | Task |
|----------|------|
| `AND_Gate.circ` | Task 1.2 — AND gate simulation |
| `OR_Gate.circ` | Task 1.3 — OR gate simulation |
| `XOR_Gate.circ` | Task 1.4 — XOR gate simulation |
| `XOR_from_basic_gates.circ` | *(Optional bonus)* XOR built from AND/OR/NOT |

## How to save a circuit in Logisim-Evolution

1. Build your circuit on the canvas
2. Go to `File` → `Save As...`
3. Navigate to this `circuits/` folder
4. Enter the exact filename shown above
5. Click **Save**

> ⚠️ Make sure to save each circuit **before** pushing to GitHub!
